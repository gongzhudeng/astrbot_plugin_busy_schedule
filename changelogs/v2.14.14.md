# v2.14.14

日程生成开始读她的生理期：这几天会自然地少排剧烈活动、多排暖一点的东西。

## 改动

### 1. 生成时读内心世界的生理期（`core/generator.py`）

新增 `_get_cycle_context(umo, target_date)`，走回调 `_emotion_state_cycle_context`：

- 对方没装 / 版本旧 / 抛异常 / 说 `available=False` → 返回空串，**不留占位**；
- 有内容时返回整段（含标题与一句约束）：

```
## 今日身体状态（软参考）
经期第2天，容易累；饮食可以暖一点，喝些热的
只体现在活动内容和强度上，不要在日程文本里写「经期第几天」这类说明。
```

最后那句约束是必须的：日程文本是每轮都注入的，一旦写进「经期第几天」，
等于绕一圈又回到对话里，把「聊天不重复注入生理期」的设计抵消掉。

### 2. 模板兜底（`core/generator.py`）

用户模板多为深度自定义（本机 6893 字，默认只有 2845），改默认模板对他们无效。
所以走两条路：

- 模板里写了 `{cycle_block}` → 按占位符渲染；
- 模板里没写 → 生成时追加到 prompt 末尾。

没有这段兜底，「升级后没反应」会是第一个反馈。

### 3. 影响程度可调（`_conf_schema.json`）

新增 `cycle_schedule_level`：轻 / 中 / 重，默认「轻」。

| 档 | 给模型的话 |
|---|---|
| 轻 | 容易累；饮食可以暖一点，喝些热的 |
| 中 | 容易累；减少外出和剧烈活动，多安排在家 |
| 重 | 人很乏；今天以休息为主 |

中文档位在代码里翻成 `light/medium/heavy` 再传给回调——面板给中文，接口收英文，两种都认。
