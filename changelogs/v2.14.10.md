# v2.14.10

- 自动修正省流：新增配置开关「无待关注事项时跳过修正」（`correction_skip_without_attention`，默认开）。
- 行为：定时修正到点先通过内心世界 live 接口检查待关注事项，为空（空串或"暂无待关注事项"占位）→ 直接跳过本次，不调修正模型（日志与修正历史记录"无待关注事项，跳过修正"）。
- 边界保护：
  - 手动「忙碌修正」不受影响（显式调用强制跑，附加要求更是必跑）；
  - 未装 emotion_state / 未提供 live 数据 / 回调异常时不跳过，照常修正（缺信息绝不跳过）；
  - 开关关闭时行为与旧版完全一致。
- schema 新增 bool 条目（default true）+ 用户配置同步加键。
